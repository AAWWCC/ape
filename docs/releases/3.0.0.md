APE 3.0.0 consolidates the autonomy, recovery, and shipping work developed since
the published 2.25.8 release.

The main changes are:

- New workers have no duration limit. Execution policy v4 uses recorded progress
  instead of fixed recovery-attempt quotas, with diagnostics for stalled or
  repeated failures.
- Durable checkpoints preserve unfinished work across blocked runs and sessions.
  Resume selects a recovery plan, and paged admission previews let larger scopes
  be inspected without fitting the entire preview into one response.
- Test handoff and attestation recovery avoid previously observed deadlocks.
  Gates retain launch ownership, stop invalidated generations, check effective
  Vitest serialization, and use the configured full-suite timeout in every build
  lane that runs the full suite.
- Shipping checks terminal pull-request state before waiting on CI and separates
  failing checks from failures to observe them. Recovery preserves the admitted
  shipping policy and GitHub host.
- Verified shipments refresh local Codex and Claude development installations
  while preserving plugin paths needed by open tasks. Windows uses the supported
  default Codex launcher.
- Claude permission hooks preserve host decisions. Patch handling preserves
  exact path identity, test helpers have supervised cleanup, Git fixtures are
  isolated, and vulnerable dependencies are updated.
- Operational canaries require proof that each promised test actually executed
  and passed. Recovery-policy tests cover progress, replay, and stalled evidence.

Upgrade behavior:

- This release keeps runtime v2 and state schema 2.0.0. The major version marks
  the accumulated workflow changes; the version bump adds no state migration.
- Existing runs retain their frozen execution policies. New defaults apply to
  newly admitted runs after the updated plugin is loaded.
- Node.js 22.12.0 remains the minimum. The host pins remain Codex CLI 0.153.4 and
  Claude Code 2.1.228; see [host compatibility](../compatibility.md).
- Command and suite timeouts, resource byte limits, and operational timers remain.
  These are separate from the removed worker deadlines and recovery quotas;
  see [runtime limits](../limits.md).

Validation and publication status:

This is the 3.0.0 release candidate. See the [validation record](../prevention-release-status.md)
for checks performed on it. Fresh live certification is not claimed, and the
owner exception for 2.25.8 does not authorize publication of this version.
