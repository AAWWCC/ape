APE 2.25.8 improves reliability and compatibility across the engineering workflow.

Changes since the original 2.25.1 snapshot:

- Codex worker defaults now use GPT-6 Astra: low effort for fast, medium for
  balanced, and high for deep. The tested Codex CLI is 0.153.4.
- Safer resume, cancellation, task persistence, crash recovery, and Windows
  file and lock handling.
- Stronger test evidence: unrelated failing tests cannot establish that newly
  authored tests fail; deleted files trigger appropriate full-suite checks.
- Correct shipping-tree identities for tracked APE configuration, with safer
  post-merge cleanup that preserves additional commits and other worktrees.
- Improved native bootstrap guidance and explicit project selection for
  receipt validation.
- Atomic configuration initialization, preserved statusline backups and user
  edits, and Node type-stripping commands for blank TypeScript projects.
- Bounded runtime file reads, duplicate/dead-code cleanup, package consistency,
  certification tooling fixes, and updated Vitest development tooling.

Existing project model selections are preserved during upgrade. Projects using
generic npm scripts, `script/test`, or Go package tests may need an explicit
`test_commands.targeted_template` for authored failing-test admission. Claude
defaults are unchanged; fresh live Claude certification is not claimed.
