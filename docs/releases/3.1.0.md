APE 3.1.0 introduces the Engineering Rules Engine ("Desloppifier"), two-tier
ephemeral test lifecycles, and smart scope discovery.

The main changes are:

- Engineering Rules Engine: Load custom natural-language architectural rules from
  `.ape/rules/*.md` and `.rules/*.md`. Pre-bundled rule packs support
  TypeScript Effect, Python Async, and Go idioms. Default anti-slop rules
  (`no-swallowed-exceptions`, `no-manual-retry`, `direct-property-access`,
  `no-redundant-wrappers`) are enforced by the reviewer as blocking findings.
- Deterministic AST/Regex Pre-Check: Added fast diff audits in receipt validation
  to catch obvious code slop (such as bare exception swallowing and busy-wait
  retry loops) in <1ms before recording worker receipts.
- Two-Tier Test Lifecycles: Formalized ephemeral acceptance traps (`*.ephemeral.*`
  and `.ape-ephemeral-tests/**`) versus permanent regression tests. Ephemeral tests
  execute during the run to prove red-to-green transitions and are sealed in run
  receipts, but are automatically pruned from final git patches and shipping diffs
  to eliminate long-term test suite bloat.
- Smart Scope Discovery: Automatically infers production and test paths from
  natural-language directive text during run preview evaluation, reducing the need
  for manual `--scope` flags on common coding runs.

Upgrade behavior:

- This release keeps runtime v2 and state schema 2.0.0. Existing runs keep their
  frozen policies.
- New rules apply automatically to newly started runs when rule files are
  present or default rules are active.
- Node.js 22.12.0 remains the minimum. Supported hosts remain Codex CLI 0.153.4
  and Claude Code 2.1.228.
