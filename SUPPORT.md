# Support

Use GitHub Discussions for setup questions, workflow guidance, and ideas. Use GitHub Issues for a
minimal reproducible defect or a scoped feature request. Include the APE version, host and host
version, Node version, operating system, relevant configuration with secrets removed, and the
smallest reproduction you can provide.

Do not attach `.ape/runtime/` state, private run records, credentials, repository secrets, or
licensed sound files. For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of
opening a public issue. Conduct concerns should also be reported privately through the repository's
security-reporting channel.

APE is independently maintained by one person and provides no guaranteed response time or
production support SLA.
